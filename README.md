# CyberMaze Kids: Escape Digital

Juego web educativo de ciberseguridad para ninos y adolescentes.

## Requisitos

- Navegador moderno (Chrome, Edge, Firefox, Safari).

## Ejecutar en local

1. Abre esta carpeta en VS Code.
2. Inicia un servidor estatico, por ejemplo con la extension Live Server.
3. Abre `index.html` desde el servidor local.

Alternativa con Node.js:

1. En terminal, dentro de esta carpeta, ejecuta:
   - `npx serve .`
2. Abre la URL que aparezca en consola.

## Estructura

- `index.html`: pantallas, modales y estructura UI del juego.
- `styles.css`: estilo visual neon/cibernetico, responsive y animaciones.
- `app.js`: logica del juego, niveles, NPCs, preguntas, puntaje, vidas y logros.

## Despliegue web

Puedes subir estos archivos directamente a cualquier hosting estatico:

- GitHub Pages
- Netlify
- Vercel (modo static)
- Firebase Hosting

No requiere build ni dependencias para produccion.

## Contenido educativo

- 3 niveles con dificultad progresiva.
- 3 preguntas por nivel (9 en total), activadas al acercarse a NPCs.
- Temas: contrasenas, mensajes sospechosos, redes sociales y proteccion digital avanzada.
